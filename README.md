# AgroMarket Catálogo

## Descripción
AgroMarket Catálogo es el módulo encargado de gestionar la información de los productos agrícolas disponibles en la plataforma. Permite registrar, actualizar, consultar y clasificar productos mediante datos como nombre, categoría, precio, disponibilidad e imágenes. Su objetivo es ofrecer un catálogo organizado, confiable y de fácil acceso, facilitando la búsqueda de productos para los clientes y optimizando la administración del inventario por parte de los vendedores.
